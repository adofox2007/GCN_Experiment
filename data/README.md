# 实验数据说明

本项目不使用外部数据集。数据分为人工构造图与固定随机种子生成图，版本为 1.0，配置见 `graph_cases.json`。

- 人工样例：3 个节点、2 条原始有向边（构成一条无向连接），节点 2 为孤立点，用于独立手算验证。
- 自动化测试：按测试文件构造孤立点、自环、重复边、无边图、零节点图、单节点图、有向图和不同特征维度。
- 数值对照：节点数 10、50、100、500；原始边数 24 至 2500；固定随机种子 20261125。
- 性能实验：节点数 10、100、500；原始边数 30、500、3000；输入输出特征维度均为 16。

边列表格式为两个等长整数数组 `src` 和 `dst`，每个位置表示一条 `src[k] -> dst[k]`。普通重复边默认保留。默认自环策略严格执行 `A + I`。

本实验是算子级正确性验证，不是模型训练，因此不人为划分训练集、验证集和测试集。人工样例负责独立预期值；随机图负责数值、梯度和性能验证，两者用途分离。

所有数据由本项目创建，不包含第三方受限内容，可随本项目代码用于学习、复现和评测。
